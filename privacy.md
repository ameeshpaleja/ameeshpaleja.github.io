# ai-lab-backup privacy policy

Last updated: November 24, 2026

ai-lab-backup is a personal backup tool used only by its owner. This policy describes how it handles Google user data.

Access: the tool requests only the Google Drive scope drive.file. It can create, read, update and delete only the files it created. It has no access to any other files.

Use: backup files are uploaded to the owner's Google Drive and read back only to restore them.

Storage: data stays in the owner's Google Drive. Sign-in tokens are stored only on the owner's own machines.

Sharing: no Google user data is sold, shared with or transferred to anyone. It is not used for advertising or to train AI models.
